# Owner review

This is a substantial working 2.0 development checkpoint, **not a declaration that the full assignment is complete**. Do not merge or deploy this draft yet.

Implemented: seven units and 30 populated lessons; five-page teaching with checks; 12 guided tasks per lesson (15 for Verb); exactly ten independent tasks; exactly 29 mixed-format test tasks; alternate contexts and retake forms; local resume/history; help tracking separate from first-attempt work; rubric-based parent writing review; sentence construction/expansion/repair/combining; paragraph, narrative, opinion, informational and Weekend News notebooks preserving originals and revisions. Exact current GaDOE wording and locations are recorded in the standards matrix.

Start review locally from index.html or a local static server. No preview has been published. Run `npm test`; install Playwright and a compatible browser to run `npm run test:browser` (BROWSER_PATH may select an installed Chromium). No student account or service key is needed.

1. Start a new path, complete the five Teach pages, and use the understanding check.
2. Try hints, I Don’t Know and Show Answer in Practice Together.
3. In On My Own, confirm help stays unavailable until an attempt. Finish all ten tasks and examine the separate counts.
4. Complete a 29-task test. Verify no help or correctness appears during the test. Leave/refresh and resume.
5. Submit, review, and use Parent Writing Review. Until writing is reviewed, mastery stays pending.
6. Start a retake and inspect the new context and Form-B response bank.
7. In Writing Lab, preserve an original, save a revision, and inspect both versions after refresh.
8. Inspect the included phone/desktop screenshots and try your actual phone.

Remaining work before full acceptance:

- Reconcile the live Build 1.8.0 branch and its larger reviewed assessment pools/mixed Grammar Check with this main-based implementation. Production is not running the main baseline. Preserve useful existing behavior and determine the actual intended deployment source before any release.
- Complete independent educational review of assembled items, distractors, rubric suitability, objective coverage and comparable difficulty across forms. The new banks are deterministic authored families; they are not externally validated assessments.
- Complete physical-device, screen-reader and child usability validation. Automated Chromium checks do not establish those results.

The current draft gives you code, instructional content, test results, screenshots and explicit remaining gaps to inspect. All development remains on the feature branch. Production was read only.
