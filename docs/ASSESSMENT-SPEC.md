# Assessment and scoring contract

Decided before implementation, 2026-10-24.

Each lesson test contains exactly 29 tasks: 26 objective items and 3 authentic writing/revision tasks. Form A selects an authored answer; Form B supplies the answer through a constrained word bank. Form B uses a separate set of 26 sentence contexts and a different response format. The grammar rules and some target forms deliberately recur, so these forms still require instructional validation rather than being claimed as psychometrically equivalent parallel assessments. No question ID or complete prompt/context pair repeats within one test.

Each objective item is worth 1 point, with stable key identity or normalized exact response against the displayed response bank. Whitespace and typographic apostrophe variants are normalized. Case is required for capitalization, dialogue and title-convention items; meaningful punctuation is retained. Original writing is never exact-match scored.

Each writing task has a displayed three-part rubric: lesson objective, complete thought/agreement, capitals/punctuation. Parent checks each criterion against the actual response, 0 or 1 each. A writing task earns 1 point only if all three criteria are met. Unreviewed work remains pending; it does not count as either automatically correct or mastered. The parent may record feedback. Original responses are preserved.

Total possible: 29. Provisional mastery requires 24/29 **and** all three writing tasks meeting their rubric. Until writing review is complete, show only “objective score n/26; writing review pending.” These local practice tests are not validated Georgia Milestones assessments and do not predict an official achievement level.

Teach has an understanding check and no mastery award. Guided practice has 12 items (15 in the broader Verb lesson, combining 12 stage-ordered production-bank items with 3 helping/linking items) with three authored hints, direct reveal, retry and explicit next. Independent practice has exactly 10 tasks (8 objective and 2 original writing). First-attempt correct without help is independent; a wrong first attempt remains outside that first-attempt count even after a later correct answer. Hints/reveals count as assistance. Writing remains pending parent review. Guided completion and assisted answers never award mastery.

Tests show neither help nor correctness until submission. Answers and item order are saved locally on each interaction. Refresh and ordinary navigation resume the exact item. Retakes alternate A/B; history is preserved. Static app assets contain answer keys and cannot protect them from developer tools. The UI must not display them early.
